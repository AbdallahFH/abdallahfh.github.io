#  LINKS FOR THIS PAGE  (projects.html)

#  Empty = nothing is shown on the page. Add a link and it appears.
#  One link per line:
#      https://example.com

#
#  Show or hide titles:
#      @title: off              hides titles for the whole page
#      https://... | notitle    hides the title for one link
#      https://... | title      shows it for one link (when the page is off)
#  Optional page heading and intro text:
#      @heading: My Videos
#      @intro: A line of text under the heading.
#
#  Lines starting with # are ignored. Delete a line to remove a link.
